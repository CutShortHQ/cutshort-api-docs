The Cutshort Public API lets you **search India's tech talent database, hire from it, and reach out to candidates** from your product, internal tools, AI agents, or automation scripts.

Prefer an AI agent in Claude or Cursor? Connect the Cutshort MCP server with your API key — see [MCP Server](/guides/mcp-server). This site is the REST reference with an interactive playground.

## What's in v1

| Endpoint | Purpose |
| --- | --- |
| [`GET /search/candidates`](/api-reference/search/search-talent-database) | **Primary** — structured + AI search, 10 results per page |
| [`GET /candidates/{talentCardId}`](/api-reference/candidates/get-candidate-detail-auto-unlock) | Full candidate detail — **auto-unlocks** locked candidates (spends one credit) |
| [`GET /jobs`](/guides/list-jobs) | List your workspace's jobs |
| [`POST /jobs`](/api-reference/jobs/post-a-job) | Post a job with auto-configured pipeline and outreach |
| [`POST /invite-to-apply`](/api-reference/outreach/invite-a-candidate-to-apply) | **First contact** — invite a search candidate to apply |
| [`POST /messages`](/guides/send-message) | **Follow-up** — reply in an existing conversation thread |
| [`GET /jobs/{jobId}/stages`](/guides/list-stages) | Pipeline stages with application counts |
| [`GET /jobs/{jobId}/applications`](/guides/list-applications) | Applications in a stage (default: Applications); includes `threadId` |
| [`GET /usage`](/api-reference/usage/api-usage-meters) | Usage meters — `used`/`limit` for unlocks, searches, messages |

**The core loop:** search candidates → get details for your shortlist (auto-unlock) → post a job → invite to apply → list applications → send follow-ups in-thread.

## Base URL

```
https://cutshort.io/api/v1
```

## What search returns

Each hit includes experience, salary, work history, education, **profileSignals** (AI-evaluated pedigree, quality, industry tags), and a **redacted resume excerpt** (~4k chars).

Search hits do **not** include candidate names, email, or phone. To get contact details and the actual resume for someone you shortlist, call [Get candidate details](/guides/get-candidate-details) — it unlocks the candidate automatically (one credit per new candidate).

## Getting API access

### In the product

If you are an **approved employer** on Cutshort:

1. Sign in at [cutshort.io](https://cutshort.io?auth=employer)
2. Go to [Settings → Integrations → API Key](https://cutshort.io/profile/hiring-settings/integrations)
3. Choose key type and click **Generate API key**

| Key type | Who can generate | What it can do |
| --- | --- | --- |
| **Eval access** | All approved employers | Search + get candidate details, within small quotas (10 unlocks, 100 searches per cycle) |
| **Production access** | Workspaces with production API enabled | Everything, with higher workspace-specific quotas — adds job posting and candidate messaging |

<Note>
  The **API Key** section appears only for approved employers. If you don't see it, complete employer verification on Cutshort first.
</Note>

### Request production access

Eval keys are available immediately — use them to try the core search → get-candidate experience. To upgrade to **production** keys with higher limits and the full endpoint set, email **[hello@cutshort.io](mailto:hello@cutshort.io?subject=Cutshort%20API%20production%20access%20request)** with your workspace name and use case.

See [Authentication](/authentication) for headers, scopes, and key handling.

## API support

For API questions, integration help, or quota issues, email **[engineering@cutshort.io](mailto:engineering@cutshort.io?subject=Cutshort%20API%20support)**. Send the mail from the email address on your Cutshort account so we can identify your workspace.
