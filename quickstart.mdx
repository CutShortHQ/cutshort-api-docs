## 1. Generate an API key

1. Open **Settings → Integrations → API Key**
2. Select **Eval access** (read-only) — available to all approved employers
3. Click **Generate API key**
4. Copy the `cs_live_…` value from the confirmation modal

Need **Production access** (all scopes)? Your workspace must have production API enabled — email [hello@cutshort.io](mailto:hello@cutshort.io?subject=Cutshort%20API%20production%20access%20request), then choose **Production access** when generating a key.

## 2. Search candidates

<CodeGroup>

```bash curl
curl -s -G "https://cutshort.io/api/v1/search/candidates" \
  -H "Authorization: Bearer cs_live_YOUR_KEY" \
  --data-urlencode "q=senior backend engineer python django" \
  --data-urlencode "minexp=4" \
  --data-urlencode "maxexp=10" \
  --data-urlencode "locations=Bengaluru+%28Bangalore%29" \
  --data-urlencode "page=1"
```

```python Python
import requests

API_KEY = "cs_live_YOUR_KEY"
params = {
    "q": "senior backend engineer python django",
    "minexp": "4",
    "maxexp": "10",
    "locations": "Bengaluru (Bangalore)",
    "page": 1,
}

resp = requests.get(
    "https://cutshort.io/api/v1/search/candidates",
    headers={"Authorization": f"Bearer {API_KEY}"},
    params=params,
    timeout=60,
)
resp.raise_for_status()
data = resp.json()
print(f"Found {data['totalCount']} matches, showing {len(data['results'])} on page 1")
for hit in data["results"]:
    print(hit["headline"], hit["experience"], "yrs")
```

```javascript JavaScript
const params = new URLSearchParams({
  q: "senior backend engineer python django",
  minexp: "4",
  maxexp: "10",
  locations: "Bengaluru (Bangalore)",
  page: "1",
});

const res = await fetch(
  `https://cutshort.io/api/v1/search/candidates?${params}`,
  { headers: { Authorization: "Bearer cs_live_YOUR_KEY" } }
);
const data = await res.json();
console.log(data.totalCount, data.results.length);
```

## 4. Check usage

```bash
curl -s "https://cutshort.io/api/v1/usage" \
  -H "Authorization: Bearer cs_live_YOUR_KEY"
```

Returns `searches.structured`, `searches.ai`, `apiUnlocks` (profile download credits), and subscription metadata for the current billing period.

## 5. Get contact info (production keys)

Eval keys can search but cannot unlock. With a **production key**, after shortlisting a candidate from search:

```bash
# Check profile download credits
curl -s "https://cutshort.io/api/v1/usage" \
  -H "Authorization: Bearer cs_live_PROD_KEY"

# Unlock (1 credit per candidate)
curl -s -X POST "https://cutshort.io/api/v1/candidates/TALENT_CARD_ID/unlock" \
  -H "Authorization: Bearer cs_live_PROD_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'

# Fetch email and phone
curl -s "https://cutshort.io/api/v1/candidates/TALENT_CARD_ID" \
  -H "Authorization: Bearer cs_live_PROD_KEY"
```
